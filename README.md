# Архитектура квиза

Система состоит из пяти независимых модулей: четыре класса, отвечающие каждый
за свою часть поведения квиза, и один класс-координатор, который их создаёт и
связывает между собой.

**QuizCoordinator**
   **QuizNavigation(**переключение активного шага)
   **QuizProgressBar(**прогресс-бар, счётчик, кнопка "назад")
   **QuizValidation(**валидация, кнопка "далее")
   **QuizStepTimers(**отложенные действия на шаге (таймеры))

## Главный принцип

**Ни один из четырёх классов не знает о существовании других.** Каждый из них:

- получает `steps` (список DOM-шагов) и один или несколько колбэков через
конструктор;
- трогает DOM только в своей собственной зоне ответственности;
- сообщает о происходящих событиях наружу только через колбэки, никогда не
вызывая методы других классов напрямую.

Всё связывание происходит в `QuizCoordinator.init()` — это единственное место
в проекте, которое одновременно знает обо всех четырёх классах.

Такое разделение даёт: 

- каждый класс можно читать, тестировать и менять в
изоляции;
- связи между модулями видны в одном месте, а не размазаны по всему
проекту.
